# Standalone bench routes and the tips and run time objective

Choose **Fewer tips and shorter run time** in Decide. The default objective and the default comparison CLI still use the existing labour ranking. For the new objective, **Design a complete setup** searches proposed devices as well as handler setups. **Accessible now** and **Existing + upgrades** take bench devices you add under **Your equipment**. An installed route needs affirmative access and any required separate device access in every scope. Purchase routes are hypothetical. A plate and cassette answer is the caller's declaration for the proposed configuration, and should be reviewed when either changes.

The rank compares upper tip count, upper elapsed time, then lower tip count and lower elapsed time. Ties proceed to the largest upper estimate of addition spread and to extra reagent volume. Hands-on time, visits, remaining questions and stable identity break remaining ties. Missing spread or extra reagent never improves a rank. The comparison uses the same evaluated steps and recorded ranges on both sides. A candidate with incomplete tip count, elapsed bounds, essential compatibility, unresolved physical checks or unclassified work stays unassessed for this objective. The manual baseline remains visible, including when elapsed time is incomplete.

## What the person and device do

The assessed standalone dispenser route uses one catalogued device, charged manual moves for each plate in each direction, attendance during dispensing, and existing setup, cleanup and reagent-load estimates. It uses the planner's normal physical checks and reagent accounting. Only simple non-contact additions to complete plates with explicit labware are eligible for this branch. The device volume range and manufacturer timings must cover the same plate density and tested volume or a bracket within measured volumes. A declared plate and cassette fit does not supply missing timing or liquid evidence. Specialized handling stays with the person when evidence is missing. The two off-deck directions are charged only when the recorded device position differs from the source position. On-deck dispensing uses the existing deck path.

Decide shows the chosen mechanism and one actually evaluated alternative for each shared addition and wash component, where the comparison has both. The action estimate includes associated plate moves. Setup, priming and cleanup contribute to the run estimate. Spread is an upper estimate derived from the device's cycle per plate or, where within-plate timing is unavailable, the duration of the whole addition action. A wash's tip-free addition and its tipped removal remain separate contributions. When the eligible search cannot supply the other mechanism, the table shows that the paired estimate is unavailable. It never projects a hypothetical full tip-free wash from a dispenser's addition alone.

The EL406 and VIAFLO 96 are reference entries under **One device on the bench**. The EL406 specification reports wash configurations and selected timing points. A compatible exact manifold, aspiration geometry and matched cycle are required for the modeled wash. INTEGRA describes the VIAFLO 96 as a handheld multichannel pipette. A matched head, plate and tip-use plan with attended cycle bounds is required for a ranked route. The current benchmark supplies this evidence for a narrow dispenser case. [EL406 specifications](https://www.agilent.com/cs/library/specifications/public/el406-technical-details-5994-5497EN-agilent.pdf), [VIAFLO manufacturer reference](https://www.integra-biosciences.com/united-kingdom/en/electronic-pipettes/viaflo-96-viaflo-384), [Multidrop manufacturer manual](https://www.thermofisher.com/TFS-Assets/LPD/Catalogs/multidrop-combi-user-manual-english.pdf)

Standalone results are planning estimates, with no handler deck, pipette configuration or hardware export. Local availability and experimental qualification require separate evidence. Existing exporter safeguards continue to apply to handler routes.

The hosted API still bounds requests to 192 samples. The private decision download and v1 API result include the new route and mechanism fields only when the caller selects the new objective. Existing protected workflows, exports and equipment permissions use their established entry points.
